Markatze-Lengoaiak: Webgunearen Egitura Semantikoa eta Diseinua

Orri honetan Markatze-Lengoaiak irakasgaian landutako ezagutza guztiak biltzen dira: 1. Erronkako webgune estatikoa nola diseinatu eta programatu dugun, erabilitako HTML5 egitura semantikoa, CSS3 estilo-sistema zentralizatua, osagai teknikoak (taulak, formularioak, zerrendak, kode-kutxak) eta diseinu erantzunkorra (Responsive Design).

HTML5 Egitura Semantikoa CSS3 Estiloak eta Diseinua

1. Proiektuaren Direktorio-Egitura eta Fitxategien Antolaketa

Webgune estatiko garbi, modular eta mantengarria lortzeko, fitxategiak fitxategi-mota eta helburuaren arabera antolatu ditugu src/ direktorioan:

src/ │ ├── index.html # Hasierako aurkezpen orria eta erronkaren laburpena ├── sareak.html # Sareetako atala: OSI 1-2, ASCII, CRC-6 eta modulazioa ├── digitalizazioa.html # Digitalizazio atala: IT/OT, THD teknologiak eta Cloud ├── datubasea.html # Datu-base atala: ER diagrama eta 7 taula normalizatuak ├── markatze.html # Markatze-lengoaiak: Webgunearen garapen teknikoa ├── kontaktua.html # Windows Server azpiegitura, taldea eta inprimakia │ ├── css/ │ └── style.css # Estilo-orri bakarra eta zentralizatua orri guztientzat │ └── img/ ├── logo.svg # Taldearen logotipo bektoriala (SVG) └── modulazioa-manchester.svg # Seinaleen modulazio eta kodifikazio bektorea

Fitxategiak horrela banatzeak hainbat abantaila eskaintzen ditu:

  • Estilo zentralizatua: CSS fitxategi bakarra (css/style.css) erabiliz, kolore edo tamaina aldaketa batek automatikoki orri guztiei eragiten die.
  • Bektore arinak (SVG): Logotipoak eta modulazio-marrazkiak SVG formatuan gorde dira; horri esker, edozein pantaila-bereizmenetan kalitate-galerarik gabe eta karga-abiadura azkarrez bistaratzen dira.
  • Nabigazio erlatiboa: Orri guztiak src/ erroan daudenez, orrien arteko estekak zuzenak dira (adibidez, href="sareak.html"), inolako bide konplexurik gabe.

2. HTML5 Egitura Semantikoa eta Orrien Txantiloia (IE1)

Webgune osoan koherentzia mantentzeko eta irisgarritasun estandarrak betetzeko, orri bakoitzak HTML5 egitura semantiko bera jarraitzen du. Horrek etiketa generikoen (antzinako <div> gehiegizkoen) ordez, beren esanahia adierazten duten etiketak erabiltzea dakar:

Etiketa Semantikoa Kokapena Webgunean Funtzioa eta Arrazoi Teknikoa
<!DOCTYPE html> Fitxategiaren 1. lerroan Dokumentua HTML5 estandarrean idatzita dagoela jakinarazten dio nabigatzaileari.
<html lang="eu"> Dokumentuaren erroa Edukiaren hizkuntza nagusia euskara dela adierazten du (pantaila-irakurleek eta bilatzaileek ahoskera zuzena aplikatzeko).
<head> Dokumentuaren goiburua Metadatuak (charset="UTF-8", viewport), orriaren izenburua (<title>) eta kanpoko CSS fitxategiaren lotura (<link>).
<header> Orriaren goiko banda finkoa Logotipoa eta webguneko orri nagusiak lotzen dituen nabigazio-barra nagusia (<nav>).
<nav> Header barruan Orrien artean nabigatzeko esteka-zerrenda egituratua (<ul> eta <li>).
<main> Gorputz zentrala Orriaren eduki nagusi eta bakarra. Orri bakoitzak <main class="container"> bakarra dauka.
<section> Main barruan Gai bakoitza modu independentean taldekatzeko atalak (bakoitzak bere <h2> izenburuarekin).
<footer> Orriaren oin-aldea Zentroaren informazioa, zikloa, ikasturtea, aurkibide osagarria eta egileen copyright oharra.

Txantiloi Semantikoaren Kodearen Adibidea

Hona hemen webguneko orri bakoitzaren oinarrizko hezurdura:

<!DOCTYPE html> <html lang="eu"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Orriaren Titulua - 1. Erronka</title> <link rel="stylesheet" href="css/style.css"> </head> <body> <header> <div class="container nav-bar"> <div class="logo"> <a href="index.html"><img src="img/logo.svg" alt="Logotipoa"></a> </div> <nav> <ul class="menu-zerrenda"> <li><a href="index.html">Hasiera</a></li> <li><a href="sareak.html">Sareak</a></li> <!-- Gainerako estekak --> </ul> </nav> </div> </header> <main class="container"> <section> <h1>Orriaren Izenburu Nagusia</h1> <p>Atalaren sarrera paragrafoa...</p> </section> <section> <h2>Azpiatala</h2> <p>Garapen teknikoa...</p> </section> </main> <footer> <!-- Oin-orriaren blokeak eta egile-eskubideak --> </footer> </body> </html>

3. Nabigazio-Menua eta Orrien Arteko Erlazioak (IE2)

Webgune baten erabilgarritasunaren (UX - User Experience) gako nagusietako bat nabigazio arin eta argia eskaintzea da. Horretarako, hainbat teknika uztartu ditugu:

  • Orri aktiboaren adierazpena (.aktiboa klasea): Erabiltzaileak uneoro jakin dezan webguneko zein orrialdetan dagoen, orri bakoitzeko dagokion <a> estekari class="aktiboa" ezarri diogu. Estilo-orrian gorriz (#e50914) nabarmentzen da, erabiltzaileari kokapen-erreferentzia garbia emanez.
  • Menu itsaskorra (Sticky Header): CSS bidez position: sticky; top: 0; z-index: 100; konfiguratu dugu goiburuan. Horri esker, erabiltzaileak orrian behera korritzen duenean (adibidez datubasea.html-ko 7 taula luzeetan), menua beti pantailaren goialdean finko geratzen da, beste atal batera salto egiteko orriaren hasierara igo beharrik gabe.
  • Barne-Aingurak (Anchor links): kontaktua.html orriko hero atalean href="#formularioa" motako barne-esteka ezarri dugu, botoia sakatzean zuzenean orriaren barruko formulario-eremura jaisteko. Era berean, orri honetako goiko botoiek #html-egitura eta #css-diseinua ataletara eramaten dute.
  • Nabigazio erlatiboa: Orri guztiak maila berean kokatuta daudenez, bide erlatibo garbiak erabili ditugu (href="datubasea.html", href="css/style.css", src="img/logo.svg"), proiektua edozein zerbitzarira edo karpetara mugituta ere bideak hautsi ez daitezen.

4. Webgunean Erabilitako HTML Osagai Aurreratuak

1. Erronkako irakasgai bakoitzeko eduki teknikoak modu argi eta profesionalean aurkezteko, HTML5-ek eskaintzen dituen elementu desberdinak erabili ditugu:

A) Datu-Taulak (<table>, <thead>, <tbody>, <tr>, <th>, <td>)

Informazio trinkoa eta erlazionala egituratzeko erabili ditugu:

  • sareak.html: Pasahitzaren ASCII, hamaseitar eta bitar baliokideak erakusteko taula.
  • digitalizazioa.html: IT eta OT inguruneen arteko konparaketa eta Cloud zerbitzuen taulak.
  • datubasea.html: Streaming plataformaren 7 taula normalizatuak (eremuak, datu-motak, murrizketak eta deskribapenak). Gako nagusiak (<span class="gako-pk">PK</span>) eta kanpo-gakoak (<span class="gako-fk">FK</span>) bereizteko txarteltxoak diseinatu ditugu.
  • kontaktua.html: Taldekideen eginkizun teknikoen banaketa taulan.
<!-- Datu-baseko taula baten HTML egitura adibidea --> <div class="taula-edukiontzia"> <table> <thead> <tr> <th>Eremua</th> <th>Datu-Mota</th> <th>Gakoa</th> <th>Murrizketa</th> </tr> </thead> <tbody> <tr> <td><strong>id_erabiltzailea</strong></td> <td>INTEGER</td> <td><span class="gako-pk">PK</span></td> <td>AUTO_INCREMENT, NOT NULL</td> </tr> </tbody> </table> </div>

B) Zerrenda Egituratuak (<ul> eta <ol>)

Informazio kontzeptuala eta sekuentziala bereizteko bi zerrenda mota nagusi erabili ditugu:

  • Zerrenda desordenatuak (<ul class="zerrenda-arrunta">): Kontzeptu independenteetarako (adibidez, IT eta OT ezaugarriak, RAID motak). CSS bidez ezkerreko ertz gorri bereizgarria (border-left: 4px solid #e50914) eman zaie.
  • Zerrenda zenbatuak (<ol class="zerrenda-zenbatua">): Hurrenkera kronologikoa duten prozeduretarako (adibidez, index.html-ko aurkibidea, Wi-Fi bidezko konektagarritasun-frogaren urratsak eta Windows Server-eko konfigurazio-faseak).
  • Zerrenda habiaratuak: kontaktua.html orrian <ol> zerrenda nagusiaren barruan <ul> azpizerrendak txertatu ditugu konfigurazio-atal bakoitzaren azpipuntuak zehazteko.

C) Harremanetarako Formulario Semantikoa (<form>)

kontaktua.html orrian erabiltzailearen elkarrekintzarako inprimakia txertatu da, HTML5 kontrol estandarrekin:

  • <label for="...">: Irisgarritasuna bermatzeko eremu bakoitza bere etiketarekin lotuta dago id bidez.
  • <input type="text"> eta <input type="email">: Erabiltzailearen izena eta posta elektronikoa biltzeko, required atributuarekin balidazio automatikoa aplikatuz.
  • <select> eta <option>: Erabiltzaileak kontsultatu nahi duen departamentua edo irakasgaia (Sareak, Digitalizazioa, Datu-baseak, Azpiegitura) aukeratzeko zabalgarria.
  • <textarea rows="5">: Mezu luzeagoak sartzeko testu-eremua.
  • <button type="submit"> eta <button type="reset">: Datuak bidaltzeko eta eremuak garbitzeko botoiak.

D) Kontsola eta Kode-Kutxak (.kode-kutxa)

Datu tekniko zehatzak lerrokatuta mantentzeko karaktere-zabalera finkoko iturria (monospace) eta white-space: pre propietatea erabili ditugu. Horrela lortu dugu:

  • sareak.html orrian CRC-6 zatiketa bitarra zutabez zutabe lerrokatuta bistaratzea, nabigatzaileak espazio bikoitzak jan gabe.
  • datubasea.html orrian eredu erlazionalaren eskema eta taulen arteko gako-loturak kontsola itxuran azaltzea.

E) Testuaren Formatu Berezidunak

Zientzia eta teknologia ikurrak zuzen adierazteko etiketak erabili ditugu:

  • <sup>: Berretzaileak adierazteko (adibidez, CRC-6-GSM polinomio sortzailea: x<sup>6</sup> + x<sup>5</sup> + x<sup>3</sup> + x<sup>2</sup> + x + 1).
  • <code>: Testu arruntaren barruko komandoak, fitxategi-izenak eta IP helbideak nabarmentzeko (adibidez, ping 192.168.1.10).
  • <strong> eta <em>: Garrantzia eta enfasi semantikoa emateko.

5. CSS3 Estilo-Sistema Zentralizatua (css/style.css) (IE1)

Webgune osoaren itxura bisuala zentralizatuta dago css/style.css fitxategian. Proiektuak streaming plataforma baten inguruan diharduenez, estetika iluna eta korporatiboa aukeratu dugu (Netflix plataforman inspiratutako beltz eta gorri konbinazioa):

Proiektuko Kolorea Kode Hamaseitarra Erabilera Webgunean
Beltz Iluna #141414 Orriaren atzeko plano nagusia (body). Begientzako erosoa eta kontraste handikoa.
Txartel Beltza #1f1f1f / #262626 Hero atala, txartelak, zerrendetako elementuak eta taulen atzeko planoa.
Gorri Korporatiboa #e50914 Botoi nagusiak, orri aktiboaren marka menuan, h2 azpimarrak eta taula-goiburuen testua.
Zuri Garbia #ffffff Izenburu nagusiak (h1, h2), menu estekak eta botoien testuak.
Gris Argia #cccccc / #888888 Paragrafoetako testu arrunta eta oin-orriko oharrak, irakurgarritasun lasaia bermatzeko.
Urdina eta Laranja #38bdf8 / #f59e0b Gako nagusiak (PK - laranja) eta kanpo-gakoak (FK - urdina) bereizteko txarteltxoak.

CSS Hautatzaileen Antolaketa

Estiloak hiru motatako hautatzaileen arabera antolatu dira garbitasuna bermatzeko:

  1. Etiketa-hautatzaile orokorrak: HTML etiketa oinarrizkoei aplikatzen zaizkie itxura bateratua lortzeko:
    * { box-sizing: border-box; margin: 0; padding: 0; } body { font-family: Arial, Helvetica, sans-serif; background-color: #141414; color: #ffffff; line-height: 1.6; }
    box-sizing: border-box arauari esker, elementuen betegarriak (padding) eta ertzek (border) ez dute elementuaren azken zabalera handitzen, maketazio-akatsak ekidinez.
  2. Klase-hautatzaileak (.class): Berrerabilgarriak diren osagaietarako euskarazko izen adierazgarriekin:
    • .container: Orriaren eduki guztia zentratuta mantentzen du (max-width: 1120px; margin: 0 auto;).
    • .nav-bar eta .menu-zerrenda: Flexbox bidez logotipoa ezkerrean eta menua eskuinean lerrokatzen ditu.
    • .hero-kutxa: Orriaren aurkezpen-bloke nagusia, ertz borobildu eta atzeko plano ilunagoarekin.
    • .rol-sarea eta .rol-txartela: Hasierako orriko 5 arlo teknikoak txartel moduan bistaratzen dituen sare malgua.
    • .botoi-gorria eta .botoi-grisa: Ekintza-botoi deigarriak trantsizio eta hover efektuarekin.
    • .taula-edukiontzia: Taulak biltzen dituen kaxa, mugikorretan alboko korritze-barra (overflow-x: auto) gaitzen duena.
  3. Identifikadore-hautatzaileak (#id): Orrian behin bakarrik agertzen diren elementu espezifikoetarako, hala nola barne-nabigazioko aingurak (#formularioa, #html-egitura, #css-diseinua) eta formularioko eremuen etiketak (#izena, #email, #mezua).

6. Diseinu Erantzunkorra eta Mugikorretarako Egokitzapena (Responsive)

Gaur egungo webgune batek edozein gailutan (ordenagailu, tableta edo telefono mugikorrean) modu egokian bistaratu behar du. Hori lortzeko bi zutabe nagusi erabili ditugu:

  • Metadatuen Viewport konfigurazioa: HTML orri guztietako <head> atalean <meta name="viewport" content="width=device-width, initial-scale=1.0"> jarri dugu, nabigatzaileak orria pantailaren benetako zabalerara egokitu dezan eskala artifizialik gabe.
  • CSS Flexbox eta Grid: Goiburuko menua (.nav-bar), aurkezpeneko kutxa (.hero-kutxa), arlo teknikoen txartelak (.rol-sarea) eta oin-orria (.footer-edukia) Flexbox bidez maketatu dira. Pantaila txikitzen denean elementuak automatikoki egokitzen dira (flex-wrap: wrap).
  • Taulen korritze horizontala: Datu-baseko eta sareetako taula handiak pantaila estuetatik atera ez daitezen, .taula-edukiontzia klaseari overflow-x: auto; ezarri zaio. Horrela, mugikorrean taula behatzarekin albora mugitu daiteke orriaren gainerako edukia desitxuratu gabe.
  • Media Queries (@media): Pantaila zabalera 768px baino txikiagoa denean, orriaren egitura zutabe bakarrera pasatzen da:
/* 768px baino pantaila txikiagoetarako egokitzapena */ @media (max-width: 768px) { .nav-bar { flex-direction: column; align-items: flex-start; } .menu-zerrenda { width: 100%; } .hero-kutxa { flex-direction: column; } h1 { font-size: 23px; } }

Egokitzapen honi esker, Sareak atalean ikasleok Wi-Fi bidez mugikorretik egindako konektagarritasun-proban webgunea primeran irakurri eta nabigatu ahal izan zen.

7. Web Kalitatea, Irisgarritasuna eta IIS Zerbitzarian Argitaratzea

Garapen osoan zehar web garapeneko praktika onak eta kalitate-irizpideak errespetatu ditugu:

  1. W3C Arauen Araberako Balidazioa: Kode semantikoa eta etiketen itxiera zorrotza errespetatu da, nabigatzaile desberdinetan (Chrome, Edge, Firefox, Safari) portaera berdina bermatzeko.
  2. Karaktere-Kodifikazioa (UTF-8): Dokumentu guztietan <meta charset="UTF-8"> ezarrita dagoenez, euskarazko karaktere bereziak (akentuak, tildeak, marratxoak eta ikurrak) arazorik gabe bistaratzen dira.
  3. Irisgarritasuna (Accessibility): Kontraste altuko koloreak erabili dira (testu zuria atzeko plano beltzaren gainean), irudi guztiek beren deskribapena dute alt atributuan eta inprimakiko eremu guztiek <label> erlazionatuak dituzte.
  4. Windows Server IIS Integrazioa: Webgune estatiko osoa Windows Server-eko Internet Information Services (IIS) zerbitzarian argitaratu da (E:\Webgunea\Erronka1 direktorioan, RAID-1 bolumenean babestuta). Webgune estatikoa denez (HTML5, CSS3 eta SVG fitxategi hutsez osatua), ez du datu-base dinamikorik edo zerbitzari-lengoaia konplexurik behar, eta berehala zerbitzatzen da 80 atakan abiadura bikainarekin.
