Datu-Basea: ER Diagrama, Eredu Erlazional Normalizatua eta Ofimatika

1. Erronkako jarraibideen arabera, diseinatu beharreko datu-baseak streaming eduki plataforma baten beharrak asetu behar ditu. Horretarako, erabiltzaileak, rolak, planak, suskripzioak, edukiak eta bistaratzeak (bisualizazioak) kudeatzen dituen egitura diseinatu eta normalizatu dugu:

  • Erabiltzaileak eta Rolak: Erabiltzaile batek hainbat rol izan ditzake bere kontuan: Infantila, Pertsonala, Familiarra...
  • Saio-hasiera eta Bistaratzea rolaren bidez: Kontuan izan da erabiltzaile batek saioa hasten duenean bere rola aukeratzen duela, eta rol horrekin egiten duela edukiaren bistaratzea. Horregatik, BISTARATZEAK taula zuzenean lotuta dago ERABILTZAILE_ROLAK taularekin (id_profila gako arrotzaren bidez).
  • Planak eta Suskripzioak: Erabiltzaileek harpidetza-plan bat kontratatzen dute (Oinarrizkoa, Estandarra, Premium) suskripzio baten bidez.
  • Edukiak: Katalogoak Pelikulak, Serieak eta Dokumentalak biltzen ditu.
  • Ofimatika Suitean Inplementatua: Diseinatutako eredu erlazionala ofimatika suite batean (LibreOffice Base / Microsoft Access) inplementatu da.

1. Entitate-Erlazio Diagrama (ER Diagrama)

Jarraian datu-basearen ER diagrama kontzeptuala ikus daiteke, entitateak, erlazioak eta kardinalitateak adieraziz:

1. Irudia: Entitate-Erlazio (ER) Diagrama. Kontuan izan BISTARATZEA erlazioak ERABILTZAILE_ROLA eta EDUKIA lotzen dituela.

2. Eredu Erlazional Normalizatua (3FN) eta Ofimatika Inplementazioa

ER diagramatik ondorioztatutako eredu erlazional normalizatua (3. Forma Normala - 3FN) 7 taulaz osatuta dago, eta ofimatika suite batean (Access) inplementatu dugu:

EREDU ERLAZIONAL NORMALIZATUA (TAULEN ESKEMA): 1. PLANAK (id_plana [PK], plan_izena, hileko_prezioa, bideo_kalitatea, max_pantailak) 2. ERABILTZAILEAK (id_erabiltzailea [PK], izena, abizenak, emaila, pasahitza) 3. SUSKRIPZIOAK (id_suskripzioa [PK], id_erabiltzailea [FK], id_plana [FK], hasiera_data, amaiera_data, egoera) 4. ROLAK (id_rola [PK], rol_mota, iragazki_maila, deskribapena) 5. ERABILTZAILE_ROLAK (id_profila [PK], id_erabiltzailea [FK], id_rola [FK], profil_izena, pin_kodea) 6. EDUKIAK (id_edukia [PK], izenburua, mota, generoa, iraupena_min, sailkapena) 7. BISTARATZEAK (id_bistaratzea [PK], id_profila [FK], id_edukia [FK], bistaratze_data, ikusitako_minutuak, amaituta)

4. Ofimatika Suitean Inplementazioa (Access)

Datu-basea ofimatika suite batean inplementatzeko jarraitutako urratsak:

  1. Datu-base fitxategia sortu: LibreOffice Base (Erronka1_Streaming_DB.odb) edo Microsoft Access (Erronka1_Streaming_DB.accdb) ireki eta datu-base berria sortu dugu.
  2. 7 Taulak diseinu-ikuspegian sortu: Eremu bakoitzari bere datu-mota egokia (VARCHAR, INTEGER, DECIMAL, DATE, BOOLEAN) eta gako nagusia (PK) esleitu dizkiogu.
  3. Erlazioak (Relationships) finkatu: Tresnak → Erlazioak leihoan gako arrotzak (FK) lotu ditugu osotasun erreferentziala (Integridad Referencial) aktibatuz.
  4. Formularioak eta Kontsultak: Erabiltzaileek rola aukeratu eta bistaratzeak erregistratzeko inprimakia eta SQL kontsultak prestatu ditugu.
