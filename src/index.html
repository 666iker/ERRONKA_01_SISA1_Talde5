Windows Server Azpiegitura: IIS, RAID Bolumenak eta Segurtasun Politika

Webgune estatiko hau argitaratzeko eta proiektuko datuak modu seguruan gordetzeko, Windows Server sistema eragilean oinarritutako azpiegitura prestatu dugu:

  • Integratutako Web-Zerbitzaria (IIS - Internet Information Services): Windows Server-ek lehenetsita dakarren Web Server (IIS) rola instalatu dugu Server Manager bitartez. Webgune estatikoaren HTML, CSS eta SVG fitxategiak C:\inetpub\wwwroot\Erronka1 karpetan kokatu dira, sare lokalean HTTP (80 ataka) bidez zerbitzatuz.
  • Disko Bolumenak eta RAID Konfigurazioa: Datuen erabilgarritasuna eta tolerantzia akatsei bermatzeko, Windows Server-eko Disk Management tresna erabiliz disko dinamikoetan oinarritutako bolumenak sortu ditugu: sistema eragilerako bolumen nagusia eta datuetarako RAID-1 (Mirrored Volume / Ispilu Bolumena) eta RAID-5 egiturak.
  • Segurtasun Politika (GPO eta Sarbide Kontrola): Zerbitzaria babesteko segurtasun politika zorrotza ezarri da: pasahitzen konplexutasuna eta iraungitzea, saio-hasiera okerren ondoriozko kontu-blokeoa, NTFS baimenak webguneko karpetetan (irakurketa baimena soilik erabiltzaile anonimoentzat) eta Windows Firewall arauak.

Erronka 1: Dokumentazio Orrien Aurkibidea

Sakatu beheko esteketan atal bakoitzaren garapen tekniko osoa ikusteko:

  1. 1. Sareak (OSI 1 eta 2 mailak, CRC-6-GSM eta Modulazioa): Ikasleek egindako kableen lotura Patch Panelera eta Switchera, pasahitzaren bihurketa ASCIIra, CRC-6-GSM (x6+x5+x3+x2+x+1) kalkulua, ASK/PSK/FSK modulazioak, Manchester kodifikazioaren marrazkiak eta hari gabeko proba mugikorretik.
  2. 2. Digitalizazioa (IT/OT, THD eta Cloud): IT eta OT kontzeptuen azalpena, Teknologia Gaitu Digitalak (THD) eta Cloud Computing eredua.
  3. 3. Datu-Basea (ER Diagrama, Eredu Erlazionala eta Ofimatika): Streaming eduki plataforma baten beharrak asetzeko ER diagrama eta eredu erlazional normalizatua (erabiltzaileak, rolak: infantila, pertsonala, familiarra; planak, suskripzioak, edukiak eta aukeratutako rolarekin egindako bistaratzeak) ofimatika suitean inplementatuta.
  4. 4. Azpiegitura, Planifikazioaren Jarraipena eta Taldearen Kontaktua: Windows Server azpiegituraren xehetasunak, lan-taldearen antolaketa eta harremanetarako inprimakia.
