Windows Server Azpiegitura, Planifikazioa eta 5. Taldea

Orri honetan 1. Erronka aurrera eramateko prestatu dugun Windows Server azpiegitura (integratutako IIS web-zerbitzaria, RAID bolumenak eta segurtasun-politika), papereko planifikazioaren digitalizazioa eta jarraipena, eta taldekideen informazioa bildu ditugu.

Taldearekin Harremanetan Jarri

1. Windows Server Azpiegitura: Web Zerbitzaria, RAID eta Segurtasuna

Erronkaren baldintzak betetzeko, azpiegitura osoa Windows Server batean prestatu dugu honako urrats eta konfigurazio hauekin:

  1. Integratutako Web-Zerbitzaria (IIS - Internet Information Services): Windows Server-eko Server Manager → Add Roles and Features laguntzailearen bidez Web Server (IIS) rola instalatu da. Webgune estatikoaren fitxategiak zerbitzariaren biltegian argitaratu dira eta 80. atakan (HTTP) entzuten jarri da sare lokaleko gailuetatik (kablez zein Wi-Fi bidez) atzitzeko.
  2. Egoerak eskatzen dituen Bolumenak (RAID Konfigurazioa): Datuen segurtasuna eta erabilgarritasuna bermatzeko, disko fisikoak Disko Dinamiko (Dynamic Disks) bihurtu ditugu Disk Management tresnan:
    • C: Bolumena (Sistema): Windows Server sistema eragilea eta IIS zerbitzua.
    • E: Bolumena (RAID-1 / Mirrored Volume): Bi diskotan ispilatutako bolumena webgune estatikoaren fitxategiak eta LibreOffice Base datu-basea gordetzeko. Disko batek huts eginez gero, zerbitzuak martxan jarraitzen du.
    • F: Bolumena (RAID-5 / Segurtasun Kopiak): Parekidetasun bidezko bolumena segurtasun-kopiak (Backup) eta erregistroak gordetzeko.
  3. Segurtasun Politika (Local / Group Security Policy): Zerbitzaria eta datuak babesteko honako segurtasun-politika ezarri da:
    • Pasahitzen Politika: Konplexutasun-baldintza aktibatuta (letra larriak, xeheak eta zenbakiak), gutxienez 8 karaktereko luzera eta 60 eguneko iraungipena.
    • Kontuen Blokeo Politika: 3 saio-hasiera okerren ondoren kontua 15 minutuz blokeatzea indarrezko erasoak (brute-force) ekiditeko.
    • NTFS Baimenak eta Firewall-a: Webguneko karpetan Administrators taldeak soilik du idazketa-baimena; web-erabiltzaileek (IIS_IUSRS) irakurketa-baimena baino ez dute.
