
  # 2. Digitalizazioa, IT/OT Konbergentzia, TGDak, Cloud Computing eta GitHub Kudeaketa

Produkzio-sektoreetan aplikatutako digitalizazioak gaur egungo teknologia eta azpiegitura-proiektuen oinarria osatzen du. Atal honetan, proiektu honetan erabilitako kontzeptu tekniko nagusiak, teknologia gaitzaileak eta hodeiko baliabideen bidez garatutako planifikazioaren kudeaketa biltzen dira.

## 2.1. Digitalizazioaren Kontzeptua eta Eragina Produkzio-Sektoreetan

### Definizioa
Digitalizazioa prozesu analogikoak edo fisikoak formatu digitalera igarotzeko eta optimizatzeko ekintza da, teknologia abangoardiakoak lan-fluxuetan integratuz. Ez da soilik informazioa digitazio bidez gordetzea, baizik eta enpresaren eragiketa-eredua eta kultura eraldatzea.

### Eragina Produkzio-Sektoreetan
Digitalizazioak eragin zuzena du ekonomiaren atal guztietan, prozesuen eraginkortasuna hobetuz, erroreak murriztuz eta datuetan oinarritutako erabakiak hartzea ahalbidetuz:

* **Lehen Sektorea (Nekazaritza eta Abeltzaintza):** Precisioko nekazaritza sentsoreen bidez. Lurraren hezetasuna neurtzea, ureztatze automatizatua kudeatzea eta abereen geolokalizazioa IoT bidez.
* **Bigarren Sektorea (Industria eta Ekoizpena):** Industria 4.0 kontzeptua. Ekoizpen-kateen automatizazio osoa (PLC), robotika kolaboratiboa, eta makineriaren egoera denbora errealean monitorizatzea mantentze-lan prebentiboak egiteko.
* **Hirugarren Sektorea (Zerbitzuak eta Merkataritza):** Merkataritza elektronikoa (E-commerce), bezeroen arreta automatizatua chatbot-en bidez, eta negozio-prozesuen kudeaketa zentralizatua (ERP/CRM).

## 2.2. IT eta OT Teknologien Konbergentzia (IT/OT Convergence)

Gaur egungo azpiegitura teknologikoetan ezinbestekoa da Informazioaren Teknologien (IT) eta Operazioen Teknologien (OT) arteko integrazioa.

### IT (Information Technology)
Enpresa-logika, datu-baseak, softwarea, cloud inguruneak eta informazioaren biltegiratze zein analisia kudeatzen ditu. Lehentasun nagusiak datuen konfidentzialtasuna, osotasuna eta eskuragarritasuna dira.
* **Adibideak:** ERP (SAP), CRM (Salesforce), Windows Server, IIS, Access/SQL Datu-baseak, Webguneak.

### OT (Operational Technology)
Hardware fisikoa, kableatzea, sentsoreak, switch-ak, PLC-ak eta industriako gailuen zuzeneko kontrola kudeatzen ditu. Lehentasuna denbora errealeko funtzionamendua, azpiegituraren jarraitutasuna eta segurtasuna (safety) bermatzea da.
* **Adibideak:** PLC (Programmable Logic Controller), SCADA sistemak, UTP Kableatze fisikoa, Switch industrialak, Patch Panel-ak, Access Point-ak (AP), Sentsore eta Aktuadoreak.

### IT eta OT Konparaketa eta Integrazio Proiektuan

| Ezaugarria | IT (Informazioaren Teknologiak) | OT (Eragiketa Teknologiak) |
| :--- | :--- | :--- |
| **Funtzioa** | Datuak kudeatzea, prozesatzea eta biltegiratzea | Gailu fisikoak, sentsoreak eta kableatzea kontrolatzea |
| **Gailu Nagusiak** | Zerbitzariak, IIS, Datu-baseak (Access/SQL), Cloud | Switch-ak, Patch Panel-ak, UTP kableak, AP-ak, PLC-ak |
| **Integrazioa Proiektuan** | Webgune estatikoa, streaming DB eta Windows Server | Cabling fisikoa, OSI 1/2 mailak eta Wi-Fi sarrera-puntua |

**Integrazioaren garrantzia:** Proiektu honetan, kableatze fisikoa (OT) eta Windows Server / IIS zerbitzaria zein datu-basea (IT) lotzen dira, azpiegitura osoak gailu mugikorren bidez komunikatzeko ahalmena izateko.

## 2.3. Teknologia Gaitzaile Digitalak (TGDak / THD)

Teknologia Habilitatzaile Digitalak (TGD/THD) enpresen eraldaketa digitala eta Industria 4.0 garatzea ahalbidetzen duten tresna teknologiko nagusiak dira. Proiektu honen testuinguruan, 11 TGD nagusiak honako hauek dira:

1. **Cloud Computing (Hodei-konputazioa):** Baliabide informatikoak (zerbitzariak, biltegiratzea, datu-baseak) internet bidez eskuratzeko gaitasuna, tokiko azpiegituren mendekotasunik gabe.
2. **Big Data eta Analytics:** Datu bolumen handiak azkar prozesatzeko eta aztertzeko teknologia, joerak aurreikusteko eta erabakiak hobetzeko.
3. **Gauzen Interreta (IoT / IIoT):** Gailu fisikoak eta sentsoreak internetera konektatzea, euren artean informazioa denbora errealean trukatzeko.
4. **Adimen Artifiziala (AI) eta Machine Learning:** Makinei giza adimenaren antzeko gaitasunak ematea (ikasteko, arrazoitzeko eta ereduak identifikatzeko).
5. **Zibersegurtasuna:** Sistemak, sareak, zerbitzariak eta datuak eraso digitaletatik eta baimenik gabeko sarbideetatik babesteko teknika eta protokolo multzoa.
6. **Robotika Autonomoa eta Kolaboratiboa (Cobot-ak):** Gizakiekin lan-eremu berean modu seguruan lankidetzan aritzeko diseinatutako robot malguak.
7. **Biki Digitalak (Digital Twins):** Sistema, objektu edo prozesu fisiko baten erreplika birtuala, denbora errealean simulazioak eta probak egiteko erabiltzen dena.
8. **Errealitate Handitua (AR) eta Errealitate Birtuala (VR):** Elementu digitalak ingurune fisikoan integratzea (AR) edo ingurune birtual murgiltzaileak sortzea (VR) trebakuntzarako eta mantentze-lanetarako.
9. **Fabrikazio Gehigarria (3D Inprimaketa):** Materiala geruzaz geruza gehituz objektu tridimentsionalak eta prototipo azkarrak sortzeko teknologia.
10. **Blockchain:** Transakzioen erregistro deszentralizatua, aldaezina eta segurua, trazabilitatea bermatzeko.
11. **Edge Computing:** Datuak iturburutik gertu prozesatzea (sentsorean edo gailuan bertan), latentzia murrizteko eta denbora errealeko erantzuna bermatzeko.

## 2.4. Cloud Computing (Hodeiko Konputazioa)

Hodeiko konputazioari esker, baliabide informatikoak (zerbitzariak, biltegiratzea, datu-baseak eta softwarea) internet bidez atzitu eta kudeatu daitezke, tokiko azpiegituren mende egon gabe.

* **Ereduak:**
  * **IaaS (Infrastructure as a Service):** Zerbitzari birtualak eta biltegiratzea (adib. Windows Server hodeiko ingurunean).
  * **PaaS (Platform as a Service):** Garapen eta argitaratze plataformak (adib. GitHub Pages).
  * **SaaS (Software as a Service):** Hodeiko aplikazioak eta kudeaketa tresnak (adib. GitHub Projects).
* **Proiektuko Abantailak:** Bertsio-kontrola, datuen erredundantzia, talde-lan sinkronizatua eta urruneko atzipen babestua.
